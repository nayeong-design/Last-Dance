차량과의 마지막 주행을 기록하는 Hyundai Pleos Connect 인포테인먼트 앱 (2600×1480 IVI).

## 로컬 실행

```bash
npm install && npm run dev   # http://localhost:5173
```

화면 아래 개발용 버튼으로 8개 화면에 바로 이동할 수 있습니다.
